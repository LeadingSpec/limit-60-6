# Часовой лимит 60/6 — рабочая панель

**Публичная демо-версия панели для отслеживания часового лимита самозанятых исполнителей.**

С октября 2026 года действует правило: если исполнитель на самозанятости работает более 60 часов в месяц на одного заказчика на протяжении 6 месяцев подряд, это становится основанием для повышенного внимания со стороны налоговых органов. Панель помогает заранее видеть, у кого из исполнителей часовой запас на исходе, — до того, как разовьётся риск переквалификации отношений в трудовые.

## Онлайн-демо

👉 **[Открыть панель](https://ВАШНИК.github.io/limit-60-6/)** — замените адрес на свой после публикации.

## Что внутри

- **Список исполнителей** с часовыми лимитами на месяц: 60 часов на одного заказчика, 120 — суммарно.
- **Цветовая индикация** запаса: зелёный / жёлтый / красный — видно на один взгляд, где зона риска.
- **Калькулятор 60/6**: вводите часы по исполнителям — панель показывает, сколько осталось до лимита и когда ожидать порога при текущем темпе.
- **Демо-данные**: панель открывается с примерами, чтобы сразу было видно, как это выглядит в работе.

## Как это устроено

- Один статичный HTML-файл, без сервера, без регистрации, без куки.
- Данные, которые вы вносите, хранятся **только в вашем браузере** (localStorage) — ни на сервере, ни в этом репозитории.
- Чтобы начать работу с реальными данными: очистите демо-примеры кнопкой в панели и внесите своих исполнителей.

## Развёртывание

Это обычный статичный файл — подойдёт любой статический хостинг:

1. Скопируйте `index.html` в свой репозиторий.
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Через минуту панель доступна по адресу `https://вашник.github.io/имя-репозитория/`.

## Важно

- Панель — **вспомогательный инструмент учёта**, а не юридическая консультация. При сомнениях в оформлении отношений с исполнителями сверяйтесь с НК РФ и консультируйтесь со специалистом.
- Проект на стадии исследования: мы изучаем, как малый бизнес учитывает время исполнителей после введения правила 60/6. Если панель оказалась полезной — напишите нам: заметки об опыте использования помогают улучшить продукт.
